## Developer

DOCZIS was developed by **Rahul Raj**, an Android and full-stack developer from Bangalore, India. His official portfolio is [rahul-raj.is-a.dev](https://rahul-raj.is-a.dev).

The site publishes structured data (JSON-LD) on every page identifying Rahul Raj as the author/creator of DOCZIS, with `sameAs` links to his portfolio, GitHub profile, LinkedIn, and the DOCZIS source repository.

## Local development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm start
```
